## 4. 已知问题 / 技术债

- `viewer.js` 631KB（gzip 159KB），卡片页与收藏册会加载；three 未动态拆分。
- 3D 无真实 GLB 资产；无模型时显示程序化占位人偶。
- 无 DRACO 解码；无 Blender 清理/剪影导出。
- Lux3D 任务只存在内存，进程重启会丢失进行中的任务；未做串行队列/并发限制。
- OUS 仅支持 `≤ blockSize` 单文件上传；超过会报“照片过大”。
- 照片预处理是同步的，未做异步队列与失败重试。
- 看板、分享卡、服务端 PDF 未做。
- 未设置 CSP/CORS；无安全头完整清单；join/assets 未限流。
- 特效/答题/3D 没有浏览器内视觉回归；需真机确认小屏遮挡、低端机掉帧、音效手势。
- `config/local.json` 当前不存在；默认 manual provider。

## 5. 恢复步骤

```bash
cd /Users/yi/project/qunhe/wellcome-to-myhome
export PATH=/opt/homebrew/opt/node@22/bin:$PATH

# 依赖（如 node_modules 还在可跳过）
npm ci --cache /tmp/npm-cache-wtm

# 验证与构建
npm run verify        # 期望 92 passed
npm run build

# 启动
npm start             # http://127.0.0.1:8080/
```

- 主人端：<http://127.0.0.1:8080/host/>（用你设置的 PIN）
- 客人端：<http://192.168.3.20:8080/>（手机需连同一 WiFi）
- 健康检查：`/api/health`

**全新开始（会丢当前房间）**：

```bash
rm -rf data
npm start   # 首次打开 /host/ 重新设 PIN、建房间
```

**启用 Lux3D**：

```jsonc
// config/local.json
{ "generation": { "provider": "lux3d" } }
```
```bash
export LUX3D_API_KEY=...
npm run build && npm start
```
