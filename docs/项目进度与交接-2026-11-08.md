## 4. 已知问题 / 技术债

- `viewer.js` 639KB（gzip 161KB）；three 未动态拆分，卡片页与收藏册都加载。
- 3D 无真实 GLB 资产；无模型时显示程序化占位人偶；`assets/presets/` 为空。
- Draco 解码器已自托管 `/draco/`（离线可用）；CSP 需保留 `script-src 'wasm-unsafe-eval'` 与 `worker-src blob:`，删掉会导致压缩模型静默回退。
- Vite 会把 three 内部默认 decoder 也打进 `dist/web/assets`（约 1.3MB 死资源，运行时不请求），属已知浪费。
- Blender 默认关闭（`generation.blenderEnabled=false`）；手动上传的 Blender 清理是 fire-and-forget，进程提前退出只保留 raw GLB。
- GLB 校验容忍头部声明长度后的尾部字节；`assets` 表按次追加审计行，无清理策略。
- Range 只支持单段（多段回退 200）。
- Lux3D 任务不持久、无队列；照片预处理同步，未做异步队列与重试。
- 限流 30/min/IP 在 NAT/大派对下可能误伤，可用 `config/local.json` 的 `server.rateLimit` 调整；`trustProxy=false` 时反代后所有请求共享代理 IP。
- 无 iOS 真机验证；无视觉回归基线（截图目前只作验收记录）。

## 5. 恢复步骤

```bash
cd /Users/yi/project/qunhe/wellcome-to-myhome
export PATH=/opt/homebrew/opt/node@22/bin:$PATH

# 依赖（node_modules 还在可跳过）
npm ci --cache /tmp/npm-cache-wtm

# 验证与构建
npm run verify        # 146 passed
npm run build
npm run test:e2e      # 3 passed（需本机 Chrome）

# 启动
npm start             # http://127.0.0.1:8080/
```

- 主人端：<http://127.0.0.1:8080/host/>（用你设置的 PIN）
- 客人端：<http://192.168.3.20:8080/>（手机需连同一 WiFi）
- 健康检查：`/api/health`

**全新开始（会丢当前房间）**：

```bash
rm -rf data && npm start   # 首次打开 /host/ 重新设 PIN、建房间
```

**启用 Lux3D / Blender**：

```jsonc
// config/local.json
{ "generation": { "provider": "lux3d", "blenderEnabled": true,
                  "blenderPath": "/Applications/Blender.app/Contents/MacOS/Blender" } }
```
```bash
export LUX3D_API_KEY=...
# 或环境变量：LUX3D_API_KEY=... BLENDER_ENABLED=true BLENDER_PATH=... npm start
npm run build && npm start
```

**在浏览器里手动验收一遍**（无 PIN 时删 `data/` 重来）：

1. `/host/` 设 PIN → 加人偶/配题/配终局 → 打印卡片 → 开局
2. 手机扫码 → 昵称 → E1 → 收藏 → 收藏册 → 答题 → 终局 → 保存分享卡
3. 主人端看板看在线/收藏/错误统计；跑自检；下载备份；试应急解锁
4. 清空数据前先备份（会清掉客人进度与照片/模型）
